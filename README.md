# 📚 How to Initialize GraphQL with Apollo Server

## 🧩 Project Description

This repository demonstrates how to build an **API using GraphQL** with **Node.js**, **TypeScript**, and **Apollo Server**, using **arrays as mock data**.  
The purpose of this example is to simulate a **Sales Store**, establishing relationships between entities where each **Sale** is associated with specific **Employees**, **Products**, and **Roles**.

---

## 📌 Entities Included

- **Employee**
- **Role**
- **Product**
- **Sale**

Each entity includes:
- Create
- Update
- Delete
- List / Query
